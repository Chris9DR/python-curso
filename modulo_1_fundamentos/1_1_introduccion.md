# 1.1 Introducción y Configuración del Entorno

## ¿Qué es Python?

Python es un lenguaje de programación:
- **Interpretado**: Se ejecuta línea por línea
- **Dinámico**: No necesitas declarar tipos de datos
- **Legible**: Sintaxis simple y clara
- **Versátil**: Sirve para múltiples propósitos

## ¿Por qué Python para Ciberseguridad?

✅ Fácil de aprender pero poderoso
✅ Librerías especializadas
✅ Automatización rápida
✅ Comunidad enorme en seguridad
